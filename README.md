# Terraria Agent

开发一个能在真实 Terraria 游戏中运行、观看、测试和继续改进的 Agent。长期目标是新档推进到月亮领主；第一天先实现观察和动作闭环，再完成砍树、拾取、制作并放置工作台，之后尝试克苏鲁之眼。

当前已用自有 Host/Bridge 实际进入专用新人物与世界，连续自身观测通过；12 秒连续录像已在播放器播放确认。此前三次 A 流程均等待人工许可超时，Agent 没有执行动作，移动、停止、跳跃尚未通过；累计死亡 4 次、人工接管 0 次，正常退出后新档已落盘。

许可事件、旧会话撤销、人工接管和急停并发边界已修复，Host、Bridge、Controller 整体编译零警告、零错误，29 项离线协议、本机回环与文件锁检查通过。窗口事件钩子的前一版已在第四次运行的菜单中安装；随后桌面工具无法识别前台窗口，测试游戏已关闭。后续控制权修复只有编译与离线检查，最新版的加载、实际接管和动作仍待游戏验证。最新结果见 [验收记录](docs/VALIDATION.md)。

B、C、D 未实现；运行时为规则，没有模型调用或付费 API。公开仓库为 [Thecats-Jfm/terraria-agent](https://github.com/Thecats-Jfm/terraria-agent)，只同步源码、脚本和验收摘要，实际同步方式见 [GitHub 说明](docs/GITHUB.md)。

## 下一步

修复自有游戏窗口的许可热键后，重新编译并进入专用新档，先确认许可可靠收到，再验收右移、停止、跳跃及正在行动时的断连释放。各安全项逐条记录；全部必需项通过后才记录 A 通过。重新进入新档及活动输入停控仍待实机验证。

当前无需 tModLoader；也不加载上游 Injector、Core、Vault、DebugTools 或可选游戏模组。自有启动入口已实际进入游戏，录制和播放能力已验证；完整动作验收和退出后重进仍未通过，不能宣称完整流程一键可用。
